# Student Developer | Personal Portfolio

A responsive personal portfolio website built with HTML5 and CSS3, featuring a sticky navigation header, profile hero section, technical skills overview, featured projects, achievements, and a contact form.

**Live Demo:** [https://vyshnavi-mamidisetti.github.io/portfolio-profile/](https://vyshnavi-mamidisetti.github.io/portfolio-profile/)

## Sections Included
- **Navigation Bar:** Quick smooth-scroll links to **Skills**, **Projects**, **Achievements**, and **Contact**.
- **Hero & Profile Card:** Introduces **Alex Verma** (Full-Stack Web Developer, B.Tech CSE '27, Frontend & Python Enthusiast) with a call-to-action button to explore projects.
- **Technical Skills:**
  - **Frontend Development:** Semantic HTML5, Modern CSS3 (Grid & Flexbox), Responsive Design, JavaScript ES6+.
  - **Backend & Databases:** Python, FastAPI, RESTful APIs, SQLite, PostgreSQL, Supabase Authentication.
  - **Tools & Workflow:** Git, GitHub, VS Code, Linux CLI, Figma Wireframing, Docker Basics.
- **Featured Projects:**
  - **EcoRoute Optimizer:** A fleet logistics dashboard predicting fuel consumption and minimizing carbon emissions across delivery routes (`HTML/CSS`, `Python`, `Leaflet`).
  - **CampusPulse Portal:** Centralized college event registration system with live seat availability and schedule filtering (`Responsive UI`, `REST API`).
  - **TaskFlow Kanban:** Minimalist productivity board with priority tagging, deadline alerts, and dark-mode styling (`CSS Grid`, `JavaScript`).
- **Achievements:**
  - **1st Place — Smart Campus Hackathon 2026:** Built an accessible real-time transit tracker in 24 hours.
  - **5-Star Problem Solver on HackerRank:** Solved 250+ algorithmic and data structure challenges.
- **Contact Form:** Interactive form with name, email, and message fields.
